Cotonetes Forever — cómo se publica
===================================

NO hay que subir archivos a ningún lado. El hosting es GitHub Pages, sobre este
mismo repositorio: todo lo que llega a la rama `main` se publica solo, en un
minuto, en

    https://cotoaprendizaje.github.io/superplannercoto/

Si hiciste un cambio y no lo ves, casi siempre es el navegador: recargá con
Ctrl+Shift+R. Para ver si la publicación salió bien, mirá la pestaña "Actions"
del repositorio en GitHub.

IMPORTANTE
- index.html es un archivo GENERADO. No lo edites a mano: se regenera con
  `npm run build` a partir de la carpeta src/, y el siguiente build te pisa
  los cambios. Hay una prueba que falla si los dos dejan de coincidir.
- El código editable vive en src/. Ver README.md.
- Antes de publicar, `npm test`. Son 70 pruebas y tardan un minuto.

Las contraseñas no se anotan acá: este repositorio es público. Cada persona
entra a la app con su propia cuenta de Supabase. Ver SEGURIDAD.md.
